# Python Recursion Exercises

This repository contains my Python recursion practice programs, created as part of my journey to strengthen my Python programming fundamentals and improve my logical thinking and problem-solving skills.

The exercises focus on understanding recursion, where a function calls itself to solve a problem by breaking it down into smaller subproblems. Through practical examples, I am learning how recursive functions work, how to define base cases, and how to control recursive calls to avoid infinite recursion.

### Topics Covered
- Understanding recursion in Python
- Writing recursive functions
- Base cases and recursive cases
- Recursive function calls
- Calculating factorials using recursion
- Fibonacci sequence using recursion
- Sum of numbers using recursion
- Reversing strings and solving number-based problems

### Objective
To develop a strong understanding of recursion and improve my ability to solve programming problems using clear, structured, and reusable Python code.

Language: Python
